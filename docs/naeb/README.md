## القانون الأعلى

> **NAEB لا يتصرف أبداً في:** رسائل العملاء، نشر production، قرارات مالية، تعديلات database — **بدون موافقة صريحة من المؤسس.**
>
> **NAEB يتصرف فوراً في:** حظر هجمات أمنية، restart كونتينر واقف، تنفيذ pre-approved patterns (بعد 5+ موافقات متطابقة).
>
> **كل شيء مسجّل في audit log لا يُمحى.**
